# 대전경찰청 웹사이트 리팩토링

기존 대전경찰청 퍼블리싱 자료를 React 기반으로 마이그레이션하고, 공공기관 정보 구조를 유지하면서 반응형 UI와 인터랙션을 개선한 개인 프론트엔드 프로젝트입니다.

**배포 사이트:** <https://hyeon924.github.io/police-website/>

> 본 프로젝트는 개인 포트폴리오 및 학습 목적으로 제작한 리팩토링 작업물입니다. 대전경찰청 또는 관련 기관이 운영하는 공식 웹사이트가 아니며, 원본 콘텐츠·이미지의 권리는 각 권리자에게 있습니다.

## 소개

기존 정적 HTML/CSS/jQuery 기반 화면을 React와 TypeScript로 전환했습니다. 메인 화면의 주요 안내 정보, 공지 탭, 관련 사이트 메뉴, 뉴스와 영상 영역을 구성하고, 역사관 페이지에는 연도별 갤러리·페이지네이션·이미지 모달을 구현했습니다.

## 주요 화면

- **홈:** 열린청장실, 관련 사이트, 메인 슬라이더, 공지 탭, 바로가기, 뉴스 및 영상 정보
- **대전경찰 역사관:** 연도 선택, 갤러리 목록, 페이지네이션, 상세 이미지 모달
- **반응형 내비게이션:** 데스크톱 드롭다운 메뉴와 모바일 메뉴 UI
- **인터랙션:** 카드·바로가기·메뉴 호버 효과와 관련 사이트 선택 드롭다운

## 기술 구성

- React
- TypeScript
- Vite
- React Router
- CSS
- GitHub Actions / GitHub Pages

## 프로젝트 구조

```text
src/
├── components/   # 공통 레이아웃 및 UI 컴포넌트
├── data/         # 메뉴, 공지, 갤러리 콘텐츠 데이터
├── lib/          # 이미지 자산 경로 유틸리티
├── pages/        # 홈 및 역사관 화면
├── styles/       # 전역 스타일
└── App.tsx       # 라우팅 및 공통 레이아웃 조합
img/              # 기존 이미지 자산
legacy/           # 이전 정적 퍼블리싱 원본
```

## 배포

GitHub Pages를 통해 배포합니다. `main` 브랜치에 변경 사항이 반영되면 GitHub Actions 워크플로가 빌드와 배포를 진행합니다.
